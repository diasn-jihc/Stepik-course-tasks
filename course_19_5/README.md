# Custom Animation — 19.5

Flutter animation course project. This is a continuation of lesson 19.4.

## Run

```bash
flutter pub get
flutter run
```

## Lesson 19.5

- `BorderRadiusTween` animates the corner radius.
- `ColorTween` animates the container color.
- `CurvedAnimation` with `Interval(0.375, 0.500, curve: Curves.ease)` controls when these effects run.
- The container is drawn with an indigo border and animated fill / rounded corners.
